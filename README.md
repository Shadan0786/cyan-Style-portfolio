# Cyan Style Portfolio

A modern and stylish portfolio website built with HTML, CSS, and JavaScript.

## 📋 Project Overview

This is a responsive portfolio website showcasing work and projects with a cyan color theme. The project demonstrates modern web design practices with a focus on clean aesthetics and user experience.

## 🛠️ Technologies Used

- **HTML** (32.2%) - Structure and markup
- **CSS** (46.4%) - Styling and layout
- **JavaScript** (21.4%) - Interactivity and functionality

## 📁 Project Structure

```
cyan-Style-portfolio/
├── index.html          # Main HTML file
├── style.css           # Stylesheet
├── script.js           # JavaScript functionality
└── README.md           # This file
```

## ✨ Features

- Responsive design
- Modern and clean interface
- Smooth animations and transitions
- Interactive elements
- Portfolio showcase section

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Shadan0786/cyan-Style-portfolio.git
```

2. Open `index.html` in your web browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (if http-server is installed)
http-server
```

3. Navigate to `http://localhost:8000` in your browser

## 💡 Usage

Simply open the website in any modern web browser. The portfolio is fully responsive and works on desktop, tablet, and mobile devices.
